# فواتير

برنامج فواتير للمحلات. كل مستخدم بيدخل بحسابه وبيحط اسم محله ولوجو خاص بيه. بيشتغل من المتصفح من غير سيرفر، وبياناته بتتحفظ على جهازه وعلى حسابه.

## الملفات
- `index.html` : الصفحة (الشكل والعناصر)
- `css/style.css` : كل الألوان والمقاسات
- `js/app.js` : البرنامج الأساسي (فواتير، عملاء، سجل، مديونين، مصروفات، موردين، مخزون، تصدير Excel، إعدادات)
- `js/cutlist.js` : مخطط التقطيع
- `js/features.js` : إضافات (تصميم الفاتورة، منتقي الألوان، ربط CutList بالفواتير)
- `sw.js` + `manifest.webmanifest` : التثبيت على الموبايل والشغل من غير نت

## التشغيل على GitHub Pages
Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root).

## ملاحظة التحديث
أي تعديل في ملف، غيّر رقم النسخة `APP_VER` في أول `js/app.js` وكمان `?v=` في سطور `index.html`. لازم الرقمين يبقوا زي بعض، والملف بنفس الرقم بيتقري من المحفوظ على الجهاز، فالتعديل مش هيوصل للمستخدم من غير رقم جديد.
